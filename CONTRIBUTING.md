# Como contribuir

Sugestões de fontes oficiais, correções de metadados, melhorias de
acessibilidade e testes em aparelhos diferentes ajudam bastante.

Antes de enviar uma alteração:

1. Leia `docs/POLITICA_DE_CONTEUDO.md` e documente a fonte.
2. Não inclua PDFs, ZIPs, dados pessoais ou cópias sem permissão no Git.
3. Execute `npm run check` e `npm test`.
4. Explique a mudança e, se visual, como ela funciona em tela pequena.

Trate todas as pessoas com respeito. Para informar vulnerabilidade ou dados
sensíveis, siga `SECURITY.md` e evite publicá-los em uma issue aberta.
