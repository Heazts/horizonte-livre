# Segurança

Não publique dados pessoais, credenciais ou detalhes de uma vulnerabilidade em
issues públicas. Quando o repositório estiver publicado, o responsável deve
configurar o recurso de divulgação privada do GitHub ou informar outro canal
privado monitorado nesta página.

Inclua os passos necessários para reproduzir o problema sem expor informações
de terceiros. Conteúdo suspeito deve ser retirado da área pública até revisão.
