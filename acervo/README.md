# Área local do acervo

Esta pasta recebe cópias de trabalho extraídas dos arquivos ZIP. Ela é ignorada
pelo Git de propósito.

Não coloque aqui arquivos que serão enviados ao repositório público. Materiais
autorizados devem ser publicados por uma rota própria, com fonte, licença,
atribuição, tamanho e checksum registrados no catálogo.

A pasta triagem contém os arquivos extraídos nesta máquina. O status de todos
eles é revisao_de_direitos até que uma pessoa responsável confirme a permissão
de redistribuição.
