# Correção e remoção

Se encontrar autoria incorreta, conteúdo sem permissão, dado pessoal ou outro
problema, informe a página ou recurso e descreva o motivo. Não envie dados
pessoais desnecessários.

Para correções que não contenham dados sensíveis, abra uma
[issue no GitHub](https://github.com/Heazts/horizonte-livre/issues/new).
Issues são públicas. Para vulnerabilidades ou exposição de dados, use a
[divulgação privada de segurança](https://github.com/Heazts/horizonte-livre/security/advisories/new).

Ao receber um pedido, a equipe deve avaliar a suspensão preventiva do acesso,
conferir a fonte e a autorização, registrar a decisão editorial e informar o
resultado a quem solicitou quando houver meio de resposta. Retirar um link do
site não garante apagar cópias presentes em outros serviços ou no histórico.
